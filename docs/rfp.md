# 개요
    1. 이름 : My Long Diary
    2. 목적 : 개인적인 일기를 매일 작성하고 영구적으로 보관. 가끔 꺼내서 읽고 추억과 영감을 되새기 위함.
    3. 포인트 
        - 감성적
        - 프라이버시 
        - 높은 마이그레이션 가능성

# 구현 필요 사항
    - 단순하고 정제된 글쓰기, 읽기 환경 제공
    - 매일 하나의 일기 -> 이어 쓰기. 
    - 하루 일기 하나에 하나의 파일. -> 앱이 더 이상 사용 불가능할 때 별도의 복호화가 가능하도록 하기 위해 
    - 중간 정도의 암호화
    - 자동 저장
    - 좌측 사이드바 일기 브라우징 - 숨기기 기능
    - markdown, text 형식으로 작성된 기존 일기 파일 임포트 기능
    - 설정: 폰트 지정, 기본 글꼴 크기 (기본은 시스템 폰트 및 세팅에 따름)
    - 설정: 일기 저장 경로 지정
    - 설정: 테마 (그레이톤의 라이트, 다크 테마를 기본으로 함)
    - windows, mac, linux 크로스 플랫폼

# 구현이 필요하지 않은 사항 
    - 글꼴, 문단 포맷 관련 기능 : 볼드, 이탤릭, 글꼴 크기, 글꼴 색상, 정렬 등.
